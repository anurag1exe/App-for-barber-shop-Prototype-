# Stylexy - Premium Barber Shop App

A premium Flutter application for booking and managing barber shop appointments.

## Features

*   **Appointment Booking:** Schedule appointments seamlessly using an interactive calendar (`table_calendar`).
*   **Ratings & Reviews:** Rate your experience and read reviews from others (`flutter_rating_bar`).
*   **Profile Management:** Manage user profiles and upload photos (`image_picker`).
*   **Local Storage:** Fast and reliable local data persistence for offline capabilities (`sqflite`, `shared_preferences`).
*   **Social Sharing:** Easily share the app or specific barbers with friends (`share_plus`).

## Getting Started

This project is a starting point for a Flutter application.

### Prerequisites

*   Flutter SDK (>=3.0.0 <4.0.0)
*   Dart SDK

### Installation

1.  Clone the repository.
2.  Navigate to the project directory: `cd stylexy`
3.  Install dependencies:
    ```bash
    flutter pub get
    ```
4.  Run the app:
    ```bash
    flutter run
    ```

## Dependencies

Key packages used in this project:

*   [`sqflite`](https://pub.dev/packages/sqflite): SQLite plugin for Flutter.
*   [`shared_preferences`](https://pub.dev/packages/shared_preferences): Persistent storage for simple data.
*   [`table_calendar`](https://pub.dev/packages/table_calendar): Highly customizable calendar widget.
*   [`flutter_rating_bar`](https://pub.dev/packages/flutter_rating_bar): A simple yet fully customizable rating bar.
*   [`image_picker`](https://pub.dev/packages/image_picker): A plugin for selecting images from the image library, and taking new pictures with the camera.
*   [`share_plus`](https://pub.dev/packages/share_plus): A plugin for sharing content.
